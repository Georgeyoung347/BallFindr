# BallFindr: Your Next Move

BALLFINDR — LANDING PAGE MASTER PROMPT

I am building a real web application called BallFindr.

BallFindr is a football recruitment and discovery platform initially focused on non-league and semi-professional football in the UK.

The long-term vision is to become a platform where football players can discover clubs, clubs can discover players, and eventually players can find football-related services such as personal trainers, coaches, physios, nutritionists and videographers.

For now, DO NOT build the entire platform.

The first task is to build the landing page and initial user journey to a very high visual standard.

The landing page needs to make people immediately understand:

BallFindr helps players find clubs and clubs find players.

It should feel like a genuine modern football technology company that could eventually become a large platform — NOT like a basic local football website.

1. BRAND

Brand name:

BallFindr

Use the spelling exactly as:

BallFindr

The brand should feel:

Modern

The design should appeal to approximately 18–35-year-old football players and non-league/semi-professional club staff.

Avoid making it look childish, gimmicky or like a Sunday-league Facebook group.

It should feel closer to:

a modern sports technology startup

a professional recruitment platform

a modern social sports application

rather than a traditional football club website.

2. CORE IDEA

BallFindr solves a simple problem.

Players often find clubs through:

WhatsApp groups

Facebook groups

Instagram

word of mouth

friends

managers they already know

This makes recruitment fragmented and inefficient.

A player may be looking for a club but not know which clubs are recruiting.

A club may need a specific player but only have access to a small group of contacts.

BallFindr brings both sides together.

The fundamental marketplace is:

PLAYERS ↔ BALLFINDR ↔ CLUBS

Players can eventually:

Create a football profile

List their position

List their location

List their playing level

Add experience

Add statistics

Add videos

Indicate that they are looking for a club

Discover clubs

Discover vacancies

Apply for opportunities

Communicate with clubs

Clubs can eventually:

Create a club profile

State their league/level

Post vacancies

Specify positions required

Specify location

Specify playing level

View suitable players

Shortlist candidates

Contact players

Manage applications

The first version does NOT need all of this functionality.

We are creating the visual foundation for the platform.

3. LANDING PAGE OBJECTIVE

The landing page should immediately communicate:

"Find your next club. Find your next player."

The primary action should be choosing between:

I'M A PLAYER

and

I'M A CLUB

These should be the two most visually important calls to action on the page.

Do not overwhelm the user with lots of buttons.

The landing page should feel extremely simple.

Create a large, visually impressive hero section.

Main headline:

The hero should immediately communicate that BallFindr is a two-sided marketplace.

18. IMPORTANT PRODUCT PRINCIPLE

This is NOT just a marketing website.

BallFindr is intended to become a real working web application.

Therefore:

Structure components properly.

Use reusable components.

Do not hardcode things unnecessarily.

Keep the architecture scalable.

Make it easy to connect a database later.

Keep player and club entities separate.

Keep navigation ready for authenticated dashboards.

Keep the design system consistent.

Eventually we will connect this to a real backend/database.

"Finally, somewhere I can actually find clubs."

"This looks like it could become the platform for non-league football."

Overall visual reference:

Modern sports technology startup + professional recruitment platform + football culture.

Think:
